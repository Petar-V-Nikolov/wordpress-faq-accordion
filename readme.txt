== Description ==

PN FAQ Accordion is a small classic WordPress plugin from [PN Scripts](https://pnscripts.com).

* Custom post type `faq_item`: the title is the question, the content is the answer.
* Shortcode `[pnscripts_faq]` prints a keyboard-friendly accordion (buttons + regions).
* The first item is open. Vanilla JavaScript; jQuery is not required.
* This plugin does not take payment and does not integrate with WooCommerce.

Files are on GitHub, or later on CodeCanyon. pnscripts.com does not sell this plugin.

== Installation ==

1. Upload the `wordpress-faq-accordion` folder to `/wp-content/plugins/`.
2. Activate **PN FAQ Accordion** through the Plugins screen.
3. Add FAQ items under **FAQs**.
4. Insert `[pnscripts_faq]` into a page or post.
